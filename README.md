# 🎬 Netflix Data Analysis — SQL Project

## 📌 Project Overview

This project focuses on analyzing Netflix movies and TV shows using SQL to uncover meaningful insights about content distribution, ratings, countries, genres, release trends, movie duration, and TV show seasons.

The project was created as a hands-on SQL data analysis project, where multiple business-style questions were solved using SQL queries and different analytical approaches.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze the distribution of Movies and TV Shows on Netflix.
- Identify the most common ratings for Movies and TV Shows.
- Analyze Netflix content by country.
- Analyze content added during the latest five-year period available in the dataset.
- Analyze content based on genres/categories.
- Identify trends in Netflix content additions over time.
- Extract meaningful insights from the dataset using SQL.
